## الشرح

هنا هيبقى في نص عربي يشرح مفهوم المتغيرات في Rust — إيه الفرق بين `let` و`let mut`،
وإيه الظل، وإيه الثوابت. المحتوى ده هيتكتب في مرحلة لاحقة بعد التحقق من
كل مثال مع الكومبايلر الحقيقي.

## المرئي

لا يوجد مرئي في هذا الدرس بعد.

## الكود

المقطع التالي هو مجرد هيكل للتحقق من أن آلية عرض الكود تشتغل صح.

```rust runnable
fn main() {
    println!("hello");
}
```

### بلوك عادي

```rust
fn main() {
    println!("hello");
}
```

### بلوك مع أسمبلي

```rust showAsm
fn main() {
    println!("hello");
}
```

## ليه بيشتغل كده

هنا بنشرح السبب الميكانيكي وراء تصرف المتغيرات في Rust. المحتوى ده هيتكتب
بعد التحقق من كل تفصيلة فعلياً.
